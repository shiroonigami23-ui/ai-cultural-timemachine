# About

The **Cultural Time Machine encyclopedia** is the reference layer of the [AI Cultural Time Machine](https://github.com/shiroonigami23-ui/ai-cultural-timemachine) project, an app for exploring past eras. It is a static site generated from Markdown articles and JSON catalogs by a Python script. The same JSON files (`history/site_src/data/*.json`) can be loaded by the app.

Every catalog page loads, live in your browser: a photo from Wikimedia Commons, the full Wikipedia article in collapsible sections, and the most-cited and newest research from OpenAlex. Articles list their sources. Dates for prehistory are approximate and debated; where historians disagree, the articles say so.
